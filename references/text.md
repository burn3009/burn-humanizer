# 文本：让意思、证据和语气相互吻合

## 注意力与趣味

先确定本次需要讲清的核心，不自动补成一篇全面综述。对于闲聊、小问题、短评，先交付最有用的内容；读者追问时再展开。对于明确要求的长文，保留论证空间，删去围绕同一观点的反复铺陈。

趣味往往在局部：一个具体动作能代替一串形容词，一个有材料支持的对照能比宏大总结更耐读。只保留能帮助理解或值得停留的细节，不给每段加金句，也不以猎奇盖过事实。

语气与读者平等。可以有明确判断，不需要不停纠正读者、替对方总结人生或宣告唯一答案。已经解释清楚的地方不要再解释为什么它很重要。

例如，练习材料只有“电机匀速转动，偏心轮通过拉索产生往复运动”。面向普通观众可写：
> 电机一直朝一个方向转，拉索却来回动。中间的偏心轮把转动变成了往复运动。

趣味在“同一个方向”与“来回”的关系，无需虚构观众震撼，也不用追加机械史概论。面向工程读者，则保留技术表达即可。

## 从内容开始

把原稿中的事实、观点、推断和修辞分开看。优先修复没有论据的结论、重复铺陈和错误归因，再改字句。以下例子均为编辑练习，例中提供的事实只在该例内有效。

| 看见的问题 | 处理方式 | 保留边界 |
| --- | --- | --- |
| “赋能、重塑、引领”代替实际变化 | 写清谁做了什么、影响谁；原稿未说明则不补造 | 品牌口号或引语按任务保留 |
| 每段先“值得注意”，再复述上文 | 直接进入新增信息，合并重复内容 | 有实际转折或提醒作用就保留 |
| 无来源的“研究显示、专家认为” | 根据现有资料核对归属；无法支持就删主张或注明待核实 | 不发明机构、年份或引文 |
| 抽象名词连缀：“实现……的进一步提升” | 找到动作与对象，恢复具体谓语 | 术语有精确定义时保持一致 |
| “不仅是 X，更是 Y”只制造气势 | 直接说实际关系，必要时补回已有论据 | 真正的递进、对比可以保留 |
| 每段同样长度，同样一句金句收尾 | 按信息重量分段，删重复的总结 | 不按句长配额随机拆分 |
| 为避免重复而不断换称呼 | 同一对象、概念用同一名称 | 文学节奏允许有意义的变化 |
| 看似周全，结尾总落到“机遇与挑战” | 回到本文已经证明的判断或当前行动 | 用户要求的展望与规范章节要保留 |

用可验证的动作取代夸大的效果，不能把动作改写成未经验证的效果。例如“新增离线保存”不等于“效率提高 30%”，也不等于“彻底解决丢稿”。

## 结构按阅读任务选择

连续论述用段落推进，比较选项可以用表，真正并列的信息可以列点，执行步骤保留编号。不要把正文切成“短标题 + 一句说明”的碎片，也不要把有用的清单强行揉成散文。

标题说清本节是什么或解决什么问题。禁止为了显得有深度擅自把具体主题升格成宏大命题；用户要文学标题时，意象需与内容有联系。

开头不必通用地交代时代背景。通知从事项开始，评议从对象与判断开始，教程从任务与必要条件开始；故事按其叙事需要进入。结尾如果已经说完，可以停下。

## 文体与作者声音

| 场景 | 编辑重点 | 常见过度修正 |
| --- | --- | --- |
| 工作消息、邮件、通知 | 事项、时间、对象、行动清楚，礼貌与关系相称 | 把礼貌全部删掉；添加催促或承诺 |
| 教学文件、课题说明 | 目标和实际活动对应，任务与评价要求可理解 | 凭空补学时、名单、成绩或学校规定 |
| 学术与研究 | 保留术语、方法、样本、局限和引文关系 | 口语化改变结论强度，删除必要限定 |
| 艺术评论、策展文案 | 用材料、空间、动作和观看关系支撑解释 | 伪造艺术家意图；把所有抽象表达都删光 |
| 个人文章、口播 | 保留作者立场，按呼吸与理解节奏组织 | 擅自添加“我曾经”、朋友故事或情绪 |
| 产品与界面文案 | 说清功能、状态、错误原因和下一步 | 每个按钮都俏皮；成功前先庆祝 |

口播可以有停顿、回指、长短句，但不能每句话单独成段、到处“你有没有发现”、频繁宣布反转。自然幽默可保留，不能为了增加人味强插笑话。

中文标点、中英间距、数字与单位按已有规范或交付标准统一。全角引号、破折号、顿号都不是可疑证据。代码、公式、引用原文、文件路径和精确转录不受一般润色规则支配。

## 少量完整示例

### 去空话，不补事实

原稿：
> 本次更新通过新增离线保存功能，全面赋能创作流程，标志着创作体验迈入全新阶段。

改稿：
> 本次更新新增了离线保存功能。

只保留原稿已给出的功能。未给出使用条件、性能或反馈，便不添加。

### 保留可用的三项列表

原稿：
> 请于周五前提交草图、材料清单和预算。

处理：原样保留。对象与期限都清楚，不为破坏“三段式”改成两项或四项。

### 保留不确定性

原稿：
> 在这 12 次测试中，增加配重后摆幅较小，但尚不能判断是否由配重变化造成。

处理：可原样保留。“增加配重能稳定摆幅”超出了材料支持范围。

### 保留专业解释

原稿：
> 电机带动偏心轮，拉索随之往复运动。这种机械结构不仅实现了运动转换，更彰显了媒介融合的无限可能。

改稿：
> 电机带动偏心轮，通过拉索产生往复运动。

去掉无依据的升华，不需要添加艺术家的态度或观众反应。

### 有条件的承诺不能删条件

原稿：
> 如材料能在周三前到货，我们预计周五完成安装。

处理：原样保留，或保持同等条件与预期语气。不得改成“周五安装完成”。

## 最后一次复读

读者能否知道每段新增了什么？重要关系是否清楚？措辞是否符合作者身份与现场？有没有新添事实、删掉条件或磨平本来有特点的表达？不必把这些问题逐条写给用户。
